## About the Project
This is a frontend development project that I created as part of my learning and practice in web development.
I designed a simple four-page static website called **TechNova** using HTML, CSS and JavaScript.
The main idea of this project was not only to make the website look good, but also to understand how different frontend concepts work together, such as semantic HTML, CSS styling, the box model, responsive design, forms and JavaScript.
## Pages in the Website
The website contains four main pages:
1. **Home** - Introduction to TechNova and its digital solutions.
2. **About** - Information about TechNova, its mission and values.
3. **Services** - Different services provided by TechNova.
4. **Contact** - A contact form with radio buttons and checkboxes.
All pages are connected through the navigation bar.
